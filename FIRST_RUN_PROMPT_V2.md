# First Run Prompt

Read `CLAUDE.md` first and treat it as the governing instruction for this project.

Your first task is to produce the first usable weekly Australia Financial Intelligence report with the minimum necessary project setup.

## Before you begin

1. Inspect the existing project structure.
2. State only material assumptions or ambiguities that could affect the result.
3. Prefer the simplest approach that can produce a high-quality report.
4. Do not build extra automation, dashboards, databases, or infrastructure unless they are required for this task.

## Execute

1. Create a `reports/` folder if it does not already exist.
2. Research the most important Australian financial-market developments from the most recent 7 days.
3. Prioritise primary sources and high-quality financial media.
4. Filter out low-value or repetitive news.
5. Select only the developments that materially affect strategy, markets, regulation, financial institutions, products, competition, or Korea–Australia relevance.
6. Produce the report using the structure defined in `CLAUDE.md`.
7. Save it as:

   `reports/YYYY-MM-DD_Australia_Financial_Intelligence.md`

8. Clearly separate:
   - Fact
   - Analysis
   - Inference
   - Uncertainty

9. Include a short watchlist for the following week.
10. Include the most important source links.

## Verify before finishing

Check that:

- the most important developments were captured;
- important claims are source-backed;
- low-value noise was removed;
- the report explains why developments matter;
- Korea-related implications are included only when genuinely relevant;
- facts and inference are clearly separated;
- the report is concise enough to read quickly but detailed enough to be useful.

If `SCORING.md` exists, score the report using it after completion.

Record only improvements that are specific, actionable, and supported by an observed weakness.

Do not change the core mission or over-engineer the project.
